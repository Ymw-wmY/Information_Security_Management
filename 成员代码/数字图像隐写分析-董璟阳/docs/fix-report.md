# 整改前后对比说明

| 对比项     | 整改前             | 整改后             |
| ------- | --------------- | --------------- |
| 输入合法性校验 | 无               | 增加数据类型、长度及编码检查  |
| 图像容量检测  | 无               | 嵌入前计算容量，不足时终止操作 |
| 文件路径检查  | 无统一检查           | 增加文件存在性及格式验证    |
| 异常处理    | 部分异常直接导致程序退出    | 增加统一异常捕获及错误提示   |
| 日志记录    | 使用 `print()` 输出 | 增加日志记录，支持运行审计   |
| 程序稳定性   | 异常输入可能导致崩溃      | 异常情况能够安全处理      |
| 数据完整性   | 超容量嵌入可能造成数据丢失   | 容量检测保证隐藏数据完整性   |

## 验证结果

完成整改后，对正常输入、异常输入、容量不足、非法文件等典型场景进行了测试。

验证结果如下：

* 输入合法性校验正常；
* 图像容量检测正常；
* 文件异常处理正常；
* 图像信息嵌入与提取功能正常；
* 位平面分析、DCT 分析及 PSNR 计算功能正常；
* 未发现新增安全问题。

综上，本次整改实现了预期的安全目标，程序安全性和稳定性均得到提升。
