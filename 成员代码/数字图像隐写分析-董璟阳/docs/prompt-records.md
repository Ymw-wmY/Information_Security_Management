# Prompt 记录

## Prompt 1：模块安全加固

### 背景说明

本项目为基于 Python 的图像信息隐藏模块，实现图像预处理、LSB 信息嵌入、信息提取、位平面分析及 DCT 频域分析等功能。现需要在保持原有功能正常运行的基础上，对模块进行安全加固，提高程序的稳定性、可靠性和安全性。

### 任务范围

对现有代码进行修改和完善，包括但不限于：

* 增加输入数据合法性校验；
* 增加图像容量检测；
* 增加文件路径及图像格式校验；
* 增加异常处理机制；
* 增加日志记录功能；
* 保持原有功能及接口兼容。

### 约束条件

* 不修改 LSB 信息隐藏算法的基本原理。
* 不降低图像隐藏效果及提取正确率。
* 不删除已有实验功能（灰度化、位平面分析、DCT 分析、PSNR 计算等）。
* 新增代码应具有较好的可读性和注释。
* 所有异常均应进行捕获并返回明确提示。
* 用户输入必须进行合法性校验。

### 禁止行为

* 不允许删除已有功能。
* 不允许直接忽略异常或使用空的 `except`。
* 不允许保存明文敏感信息。
* 不允许取消容量检测或文件合法性检查。
* 不允许降低程序安全性来换取运行效率。

## Prompt 2：安全审查

请检查修改后的代码是否满足以下要求：

* 是否进行了输入合法性校验；
* 是否进行了图像容量检测；
* 是否进行了文件存在性及格式验证；
* 是否增加异常处理；
* 是否增加运行日志；
* 是否存在资源泄露或异常退出问题；
* 是否保持原有功能正常运行。

若发现安全问题，请指出问题位置、产生原因以及整改建议。
