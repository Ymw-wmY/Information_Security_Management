# 项目约束文档

本约束文档作为 AI 辅助开发的统一约束，在每次开启新的 AI 对话时均完整提供，避免模型遗漏前期约束条件。

## 项目背景

本项目为图像信息隐藏模块，采用 LSB 算法实现秘密信息嵌入与提取，同时提供图像预处理、位平面分析、DCT 分析和图像质量评价等实验功能。

本次开发目标是在不改变原有实验功能的前提下，对代码进行安全加固。

## 功能约束

* 保留图像灰度化与缩放功能。
* 保留 LSB 信息嵌入与提取功能。
* 保留位平面分析功能。
* 保留 DCT 频域分析功能。
* 保留 PSNR 图像质量评价功能。

## 安全约束

* 所有用户输入必须进行合法性检查。
* 图像容量不足时必须终止嵌入操作。
* 图像路径必须验证是否存在。
* 图像格式必须进行校验。
* 文件读取失败必须进行异常处理。
* 程序运行异常不得直接崩溃。
* 关键操作应记录日志。
* 输出错误信息不得泄露程序内部实现细节。

## 编码规范

* 使用 Python 标准异常处理机制。
* 新增函数需添加必要注释。
* 不使用硬编码参数，统一采用常量定义。
* 保持变量命名规范。
* 保持原有代码结构清晰。

## 禁止事项

* 禁止删除已有功能。
* 禁止绕过输入校验。
* 禁止忽略异常。
* 禁止输出调试信息替代错误处理。
* 禁止降低代码可维护性。
